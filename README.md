# Harry Potter RAG Chatbot

A conversational Q&A chatbot that answers questions about the Harry Potter book series using **Retrieval-Augmented Generation (RAG)**. The model is strictly grounded — it only uses passages retrieved from the books and never relies on its training memory.

## How it works

```
User question
      │
      ├──► 1. HyDE: Claude generates a hypothetical book-style passage for the question
      │
      ├──► 2. FAISS searches the index with both the question and the HyDE passage
      │         → returns the most semantically relevant chunks from the 7 books
      │
      └──► 3. Retrieved passages are injected into Claude's context
                → Claude answers strictly from those passages and cites its sources
```

**Key techniques:**

- **RAG (Retrieval-Augmented Generation)** — separates knowledge storage (FAISS index) from reasoning (Claude), so the model can only answer from the actual book text
- **HyDE (Hypothetical Document Embedding)** — instead of searching with the raw question, Claude first writes a fake book-style passage that would answer it; this embeds much closer to real book chunks, dramatically improving retrieval on indirect or paraphrased questions
- **Strict grounding** — the system prompt forbids Claude from using its training knowledge; if the answer isn't in the retrieved passages, it says so explicitly
- **Source citation** — Claude is instructed to declare which book(s) it used; the app parses and displays this automatically
- **Prompt caching** — the system prompt uses Anthropic's `cache_control` to reduce API costs on repeated calls

## Stack

| Layer | Technology |
|---|---|
| Embedding model | `all-mpnet-base-v2` (HuggingFace, runs locally) |
| Vector store | FAISS |
| Language model | Claude Haiku (`claude-haiku-4-5-20251001`) |
| UI | Streamlit |

## Setup

### 1. Clone and create a virtual environment

```bash
git clone <repo-url>
cd llm_potter
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure your API key

```bash
cp .env.example .env
```

Edit `.env` and add your Anthropic key:

```
ANTHROPIC_API_KEY=sk-ant-...
```

Get your key at [console.anthropic.com](https://console.anthropic.com).

### 4. Build the FAISS index

The index is not included in the repo (binary files). Run once to generate it:

```bash
python3 rebuild_index.py
```

This will download the embedding model (~420MB on first run) and create `harry_potter_mpnet_index/`.

### 5. Run

```bash
python3 -m streamlit run script.py
```

The app opens at `http://localhost:8501`.

## Project structure


## Notes

- Embeddings run fully locally via HuggingFace — no OpenAI key required.
- `rebuild_index.py` reads from an existing source index and re-embeds all chunks with `all-mpnet-base-v2`.
- Conversation history is maintained within the session and resets on page refresh.
